BANKABILITY RADAR — READY TO DEPLOY

This is a React/Vite app prepared for deployment.

EASIEST DEPLOYMENT:
1. Go to https://vercel.com/new
2. Sign in.
3. If Vercel asks for a Git repository, use the Vercel dashboard's project import flow or upload this folder through Vercel's supported deployment flow.
4. The app will build with `npm run build` and publish the resulting site.

LOCAL TEST (optional):
1. Install Node.js from https://nodejs.org/
2. Open a terminal in this folder.
3. Run: npm install
4. Run: npm run dev
5. Open the localhost URL shown by Vite.

DATA:
Project/snapshot changes are stored in each browser's localStorage. Different people using the shared link will have separate local data; this is not a shared database.
